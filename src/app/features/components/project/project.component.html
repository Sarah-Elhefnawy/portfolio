School Portal - Docker Compose with 2 Services

A two-service ASP.NET MVC app fully containerized with Docker Compose. Students MVC handles CRUD operations with SQL Server, while Grades MVC communicates with Students service via HTTP. One command starts everything: docker compose up --build

What I built:
  • Students Service - Full CRUD with EF Core + SQL Server
  • Grades Service - Calls Students API via HttpClient
  • Docker Compose - Wires all services with automatic networking
  • Graceful failure handling - Grades app stays up even if Students service is down
How containers talk:

Grades app calls http://students-mvc:80/api/students using Docker service names. No hardcoded IPs!

Docker concepts I used:
Multi-stage Dockerfiles Docker Compose networking Environment variables Layer caching Named volumes
